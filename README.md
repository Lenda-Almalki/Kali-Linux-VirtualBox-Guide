# Kali-Linux-VirtualBox-Guide
 A beginner-friendly guide to downloading Kali Linux for VirtualBox.


This repository contains a beginner-friendly guide for downloading Kali Linux and running it using VirtualBox.

## 📥 Kali Linux Download

Download Kali Linux from the official website:
https://www.kali.org/get-kali/

## 📖 Manual

The manual included in this repository explains:

- The difference between the Kali Linux Installer Image and the Pre-built VirtualBox image.
- Which version to choose when using VirtualBox.
- How to download the correct Kali Linux image.
